# Project documents

Put public PDF and PowerPoint files in this folder. Use lowercase filenames with hyphens, such as `pizza-championship-skopje.pdf`.

Add the project details to `data/projects.json`, then run `node tools/build-projects.cjs`.
See [PROJECTS.md](../../PROJECTS.md) for the complete workflow and a ready-to-fill example.

Only put documents intended for public download here. This folder is deployed with the website.
